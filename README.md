# Sieben Tuerchen bis Lateinamerika

Ein Countdown-Kalender mit sieben Tuerchen, die sich vom 10. bis 16. August 2026 taeglich freischalten.

Eine einzelne, in sich geschlossene HTML-Datei: keine externen Abhaengigkeiten, kein Build.

- `index.html` — die komplette Seite
- `?vorschau=1` an die URL haengen, um alle Tuerchen vorab zu oeffnen
